# Hard-to-borrow shorting: prototype

A single-file, customer-facing mock-up of a hard-to-borrow (HTB) short-sale flow: order ticket, locate offer, risk acknowledgment, positions with borrow rate and squeeze alert tier, orders, and borrow charge ledger. All data is simulated.

## Run locally
Open `index.html` in a browser. No build step or dependencies.

## Host on GitHub Pages
1. Push this folder to a new GitHub repo.
2. Repo Settings > Pages > Source: "Deploy from a branch", branch `main`, folder `/ (root)`.
3. The site goes live at `https://<your-username>.github.io/<repo-name>/`.

Note: a public repo makes the prototype publicly viewable. Use a private repo (Pages on private repos needs a paid GitHub plan) if the design is internal.
